## 旋转与状态栈

`rotate x, y, degree` 绕点 `(x, y)` 旋转坐标系，`degree` 的单位是度，正值为逆时针、负值为顺时针。旋转中心用的是当前坐标系中的坐标。旋转只影响之后绘制的图形和文字，已经画好的内容不会跟着转；连续调用会叠加。

`push` 把当前绘图状态压栈，`pop` 恢复最近一次 `push` 时的状态。保存的内容包括坐标系（含旋转、缩放、平移）、填充色、描边色、文字颜色、虚线样式和线宽；不保存正在构成的路径，也不会撤销已经画出的图形。可以嵌套，栈为空时 `pop` 无效果。

所以只要想“临时改一下，画完就还原”，就可以用 `push`/`pop`：临时改颜色、线宽、虚线，临时 `rotate`/`scale`/`translate` 都适用。旋转只是其中一种用法：常见写法是 `push` → `rotate` → 画图 → `pop`，这样每次旋转都从同一基准开始，设置也不会泄漏到后面的图形。旋转示例见 `internal/examples/ndor/rotate.xgo`。
