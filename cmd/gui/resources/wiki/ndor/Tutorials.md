## 点和圆

实际上不可能画出一个点，但可以画一个小小的圆来代替，需要指定圆心和半径。

```c
color "black"
circle 0, 0, 2
fill
```

## 直线

严格地说是画线段。只需指明起点和终点坐标:

```c
from -20, -15
to 35, 50
stroke
```

## 曲线

可以画二次或三次贝塞尔曲线。需要指明起点、中间的控制点及终点。比如：

```c
from 0, 0
bezier 0, 35, 25, 35
stroke
```

控制点可以多加一个，成为三次贝塞尔曲线：

```c
from 0, 0
bezier 0, 25, 0, 45, 25, 35
stroke
```

## 椭圆

类似圆，需要指明椭圆中心坐标、横半轴长、纵半轴长。

```c
ellipse 0, 0, 10, 20
fill
```

## 矩形

需要指明左下角顶点以及宽和高。

```c
rectangle 0, 0, 90, 40
stroke
```

还可以画圆角矩形，只需要加一个参数指定圆角的半径即可：

```c
rectangle 0, 0, 90, 40, 10
stroke
```

## 弧

另一种画曲线的方法是画一个圆弧，但要注意圆弧毕竟不同于贝塞尔曲线，其代表的曲线非常规整，不灵活。

画弧需要先指定对应圆的参数，即圆心和半径，再指定弧的起止角度（即半径旋转角度），正值为逆时针，负值为顺时针。

```c
arc 0, 0, 40, 45, 180
stroke
```

## 椭圆弧

也可以在椭圆上截取一段得到椭圆曲线。类似圆弧，先指定椭圆的参数，再指定弧的起止角度。

```c
earc 0, 0, 40, 15, 0, 150
stroke
```

> 注意到上边的绘制动作指定为“描边”（"stroke"），你也可以改成“填充”（"fill"）看看效果，到底填充的是哪部分？

## 正多边形

祖冲之用割圆术来计算圆周率的值，就是用正多边形来模拟圆。反过来，怎么画一个正多边形？

可以先画一个圆，再把圆周均分成 n 等份，依次连接这些分割点也就形成了正n边形。

所以我们只需要指定正多边形边数和对应外接圆的参数就可以画这个正多边形。

```c
polygon 5, 0, 0, 40
stroke
```

这样就画出了一个正五边形。

> 还可以加一个参数来旋转正多边形，和前面一样，正值为逆时针旋转，负值为顺时针旋转。
> 上边的多边形画出来后是平整地“站”在画布上，最上边的边严格平行于 x 轴。让我们来旋转它：

```c
polygon 5, 0, 0, 40, 20
stroke
```

## 文字

支持在图中写简单的文字，如坐标长度等，仅支持字母和数字及常见符号，不支持汉字。

需要指定文字起点（基线左端）的位置和文字内容，如

```c
color "black"
text 0, 0, "Hello!"
```

## 裁剪

`clip` 用当前路径裁剪之后绘制的内容，路径随后被清空；多次 `clip` 取交集。例如两个相交的圆限定出的区域，再用矩形填充：

```c
circle -150, 0, 300
clip
circle 150, 0, 300
clip
rectangle -500, -500, 1000, 1000
color "black"
fill
```

## 状态的保存和恢复

可以设置所有图形的颜色和线宽；线形用 `dash` 设置，不带参数恢复实线，数字表示交替的实线/空白长度，如 `dash 8, 4`。

`push` 把当前绘图状态压栈，`pop` 恢复最近一次 `push` 时的状态。保存的是坐标系、颜色、虚线和线宽，不保存当前路径，也不会撤销已经画出的图形；可以嵌套，空栈时 `pop` 无效果。凡是“临时改一下设置，画完就还原”的场景都适用，比如临时换颜色、线宽、虚线，或临时旋转、缩放、平移坐标系。

`rotate x, y, degree` 绕 `(x, y)` 旋转坐标系，角度单位为度，正值为逆时针、负值为顺时针。它只影响之后绘制的图形和文字，已经画好的不会跟着转；连续旋转会叠加。想让多个图形各转一个角度而不互相影响，就先 `push`，旋转并画完后再 `pop`。

下面的例子故意只转 5 次：如果每次 60° 转满 6 次，就算漏了 `pop`，累计角度也是一整圈，最终朝向和初始一样，反而看不出问题。

```c
color "steelblue"
linew 2

for i <- :5 {
    push
    rotate 0, 0, float64(i)*60
    rectangle 40, -10, 160, 20
    stroke
    pop
}

// pop 之后坐标系已恢复：非正方形的矩形方向明显，容易看出它没有跟着旋转
color "orange"
rectangle -8, -25, 16, 50
fill
```
