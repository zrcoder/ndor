Turtle is a small drawing app: use code to move a turtle across a grid, turn it and lower the pen to draw shapes.

## Usage

Type XGo code in the editor on the right, then click the run button at the bottom right (or press `Ctrl+R`). The help button at the bottom left (or `Ctrl+H`) opens help and examples.

The origin is at the center of the canvas and the `y` axis points up; `step 1` covers one grid cell.

## Hello Turtle

```c
color "red"
step 5
right 90
step 5
```

> Lines starting with `"//"` are comments and are ignored.
