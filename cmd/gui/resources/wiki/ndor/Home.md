2021辛丑牛年，我迎来了第一个孩子，开始编写该项目。将来可以用这个程序引导孩子编程的兴趣。

这是一个实用又有趣的小应用，你可以用编码的形式来画图。

## 使用说明

我们将在一个二维坐标系里用`编码`的方式来画图。

`ndor`使用 [XGo](https://xgo.dev) 编程语言。

## 坐标系

和 `turtle` 一样，原点在图片中心，`x` 轴向右为正，`y` 轴向上为正。

图片大小不需要指定，它会自动围住你画出的所有内容。

## Hello Word

```c
// 设定当前颜色为浅绿
color "lightgreen"

// 定义一个圆，指定圆心和半径
circle 0, 0, 300

// 开始绘画，用当前颜色填充圆
fill
```

> `"//"`开头的行或被`"/*"`与`"*/"`包围的块是注释，会被忽略，并不参与画图。
>
> `x` 坐标从左到右，`y` 坐标从下到上，角度以逆时针为正。
