2021辛丑牛年，我迎来了第一个孩子，开始编写该项目。将来可以用这个程序引导孩子编程的兴趣。

这是一个实用又有趣的小应用，你可以用编码的形式来画图。

## 使用说明

我们将在一个二维坐标系里用`编码`的方式来画图。

`ndor`支持 [XGo](https://xgo.dev) 和 [Go](https://go.dev) 两种编程语言。

## Hello Word

```c
// 800×800 的画布，可以不指定，默认为左边图片框的大小
context 800, 800

// 设定当前颜色为浅绿
color "lightgreen"

// 定义一个圆，指定圆心和半径
circle 400, 400, 300

// 开始绘画，用当前颜色填充圆
fill
```

> `"//"`开头的行或被`"/*"`与`"*/"`包围的块是注释，会被忽略，并不参与画图。
>
> `x` 坐标从左到右，`y` 坐标从上到下
