| 操作名 | 操作说明             | 参数个数 | 参数说明                                                              |
| ------ | -------------------- | -------- | --------------------------------------------------------------------- |
| step   | 前进指定步数         | 1        | 步数，可为小数（1 步 = 1 个网格）；负数后退，如 `step -3`             |
| left   | 左转                 | 1        | 角度（度），逆时针                                                    |
| right  | 右转                 | 1        | 角度（度），顺时针                                                    |
| color  | 设置画笔颜色         | 1 或 3/4 | 颜色名称（如 "red"）、16 进制值（如 "#f00"）或 r, g, b[, a]（0～255，a 默认 255，支持透明） |
| width  | 设置画笔线宽         | 1        | 线宽（像素），默认 2；对之后的笔画生效                                |
| pen    | 抬笔或落笔           | 0 或 1   | `"up"` 抬笔移动不留痕迹；`"down"` 或无参数落笔（默认）                |
| clear  | 清空画布并重置海龟   | 0        | 海龟回原点、朝上，颜色和线宽恢复默认                                  |
| home   | 回到原点，不清空画布 | 0        | 同时恢复朝上；不改画笔样式                                            |
