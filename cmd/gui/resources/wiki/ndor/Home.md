这是一个实用又有趣的小应用，你可以用编码的形式来画图。

## 使用说明

我们在一个二维坐标系里画图。

`ndor` 使用 [XGo](https://xgo.dev) 编程语言。在右侧编辑区写代码，点击右下角的运行按钮（或按 `Ctrl+R`）执行；左下角的帮助按钮（或按 `Ctrl+H`）打开帮助与示例。

`circle`、`rectangle` 等命令只是把图形加入当前路径，要用 `fill`、`stroke` 或 `clip` 才会画出效果；`fill`/`stroke` 默认会清空路径，加参数 `preserve` 则保留。

## Hello World

```c
// 设定当前颜色为浅绿
color "lightgreen"

// 指定圆心和半径，把圆加入当前路径
circle 0, 0, 300

// 用当前颜色填充当前路径
fill
```

> `"//"`开头的行或被`"/*"`与`"*/"`包围的块是注释，会被忽略，并不参与画图。
>
> `x` 坐标从左到右，`y` 坐标从下到上，角度单位是度，逆时针为正。
