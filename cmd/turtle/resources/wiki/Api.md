| 操作名    | 操作说明                     | 参数个数    | 参数说明                                                                                                         |
| --------- | ---------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| context   | 定义画布大小                 | 2           | 画布宽和高                                                                                                       |
| color     | 设置当前颜色                 | 1 或 3 或 4 | 颜色名称（如"red"）或16进制表示的颜色值（如#f00, #ff00ff）或 rgba 值，取值范围为0～255，a默认为255，即完全不透明 |
| linew     | 设置线宽                     | 1           | 线的宽度                                                                                                         |
| turtle    | 放置海龟                     | 2           | 海龟位置，画布中心为原点，y 轴向上                                                                               |
| forward   | 向前移动并绘制               | 1           | 像素数                                                                                                           |
| back      | 向后移动                     | 1           | 像素数                                                                                                           |
| left      | 向左转                       | 1           | 角度                                                                                                             |
| right     | 向右转                       | 1           | 角度                                                                                                             |
| angle     | 设置绝对朝向                 | 1           | 角度，0 为向上，顺时针为正                                                                                       |
| jump      | 抬笔移动到指定点             | 2           | 像素坐标                                                                                                         |
| penup     | 抬笔                         | 0           | 移动时不绘制                                                                                                     |
| pendown   | 落笔                         | 0           | 移动时绘制                                                                                                       |
| home      | 回原点并面向上方，落笔       | 0           |                                                                                                                  |

海龟作图用 xgo 语法驱动，没有自定义语法。运行后会以动画逐步重放海龟的轨迹并画出坐标网格。
