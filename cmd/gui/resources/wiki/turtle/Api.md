| 操作名 | 操作说明             | 参数个数 | 参数说明                                                                 |
| ------ | -------------------- | -------- | ------------------------------------------------------------------------ |
| step   | 前进指定步数         | 1        | 步数（1 步 = 1 个网格）；负数表示后退，如 `step -3` 等价于原来的 backward 3 |
| left   | 左转                 | 1        | 角度，单位为度                                                           |
| right  | 右转                 | 1        | 角度，单位为度                                                           |
| color  | 设置画笔颜色         | 1 或 3/4 | 颜色名称（如 "red"）、16 进制值（如 "#f00"）或 r, g, b[, a]（0～255）      |
| width  | 设置画笔线宽         | 1        | 线的宽度                                                                 |
| pen    | 抬笔或落笔           | 0 或 1   | `"up"` 抬笔移动不留痕迹，`"down"`（默认）落笔绘制                         |
| clear  | 清空画布并重置海龟   | 0        |                                                                          |
| home   | 回到原点，不清空画布 | 0        |                                                                          |

> `forward` 与 `backward` 已合并为 `step`：`step 3` 前进 3 步，`step -3` 后退 3 步。
